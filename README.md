# Aurum Joyería

Tienda online de joyería de oro auténtico para el mercado colombiano. Desarrollada con Next.js, TypeScript y Tailwind CSS.

## Características

- **Diseño Premium** - Paleta elegante en negro, blanco marfil y dorado
- **Catálogo Completo** - Más de 25 productos: cadenas, manillas, aretes, dijes, anillos, tobilleras y más
- **Precios en COP** - Todos los precios en Pesos Colombianos
- **Filtros Avanzados** - Por categoría, material, quilataje y rango de precio
- **Carrito Persistente** - Guardado en localStorage
- **Checkout Colombiano** - Formulario con departamento, ciudad y dirección
- **Pedido por WhatsApp** - Generación automática de pedido
- **Panel Administrativo** - Gestión básica de productos
- **Responsive** - Optimizado para móvil, tablet y escritorio

## Tecnologías

- [Next.js 16](https://nextjs.org/) - Framework React
- [TypeScript](https://www.typescriptlang.org/) - Tipado estático
- [Tailwind CSS 4](https://tailwindcss.com/) - Estilos
- [React 19](https://react.dev/) - Biblioteca UI

## Instalación

```bash
# Clonar el repositorio
git clone https://github.com/tu-usuario/aurum-joyeria.git

# Entrar al directorio
cd aurum-joyeria

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Comandos disponibles

```bash
npm run dev      # Servidor de desarrollo
npm run build    # Build para producción
npm run start    # Servidor de producción
npm run lint     # Linter
```

## Notas sobre precios

Los precios han sido **estimados comercialmente** basados en:
- Precio vigente del oro por gramo
- Quilataje (18K, 14K)
- Peso aproximado de cada pieza
- Costos de fabricación y margen comercial
- Precios observados en joyerías colombianas

**Importante:** Los pesos son aproximados cuando no hay información verificable. Las piezas con baño de oro están claramente diferenciadas como NO oro macizo.
